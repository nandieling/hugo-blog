# 觅影 OmniPlay

觅影 OmniPlay 是一款原生开发的海报墙播放器，支持mac、win双系统。mac采用swift开发，win采用C# + .net + Avalonia UI。底层播放器核心为 MPVKit-GPL / libmpv / FFmpeg 相关组件。 ios版正在开发中。

仓库地址：https://github.com/nandieling/OmniPlay

如果有新增功能需求或发现bug，请前往仓库提交issues

开发览影前，已经买断infuse用了好几年。infuse可以说除了贵，几乎没有缺点。但还是有些许缺点，比如没有自定义功能，刮削剧集必须严格按照标准命名。否则，只有找标准命名的资源或者硬链接来刮削。加上AI大爆发，所以有心开发出这款刮削规则更宽松的播放器。以及后续开发ios版上架，看能不能挣点。本来没打算开发windows版，但是windows确实没有十分好用的海报墙播放器，所以最终还是决定开发。

## 功能特色

### UI
- UI简洁且美观，海报墙没有做过多的分类功能，只有搜索、排序功能。

### 海报墙媒体库

- 支持海报墙和分集剧照
- 采用TMDB刮削，增加了更宽松的刮削规则和自定义编辑功能。避免重命名和硬链接。

### 媒体源管理

- 支持添加本地文件夹、WebDAV、SMB。mac版因为开发一直有bug，不支持SMB直连，请在访达中挂载SMB，再在软件中添加本地文件夹，间接连接SMB。可以将访达挂载的SMB添加到开机自启
- 不需要将电影、剧集分不同文件夹进行挂载，软件自动识别。

### 自动扫描与刮削
- 支持公共 TMDB 源，也支持自定义 TMDB API Key / v4 Token。公共源API做了限制，建议注册TMDB后获取API。如果TMDB api连通测试失败，请挂代理或改host。

### 离线缓存

- 支持一键将SMB、WebDAV下的影视离线至电脑，方便外出观影。
